# Setting Up Translations in Mystery Box Builder

## 1. Open Content & Translation

![Open Content & Translation](../img/01-dashboard-menu-annotated.png)

## 2. Default text (English)

![Default text (English)](../img/02-default-text-english-annotated.png)

This is the app's default state: language shown is English, "Default Text" tab selected. These are the base strings used across the storefront widget before any translation is applied.

## 3. Switch the app's language to Japanese

![Switch the app's language to Japanese](../img/03-dashboard-language-english-annotated.png)

On the Dashboard, a "Language" dropdown (bottom right, under "Recently created mystery boxes") controls the app's own display language. Switching this to Japanese is what triggers the default-text prefill described next.

## 4. Default text is prefilled in Japanese

![Default text is prefilled in Japanese](../img/04-default-text-japanese-prefill-annotated.png)

After switching the app language to Japanese and reopening Content & Translation, the Default Text fields are already prefilled with Japanese copy (the app ships built-in Japanese defaults). Change any one field slightly (e.g. add a space) and click Save to lock these in as the new default text — do not Save if you're only previewing.

## 5. Translate into other store languages

![Translate into other store languages](../img/05-translation-french-annotated.png)

Switch back to the "Translation" tab. Pick a store language from the dropdown (here, French), then fill in each field's translation in the right-hand column — the left column always shows the English default for reference. Click Save when done.
