# Setting Up Translations in Mystery Box Builder

## 1. Open Content & Translation

![Open Content & Translation](../img/01-dashboard-menu-annotated.png)

## 2. Default text (English)

![Default text (English)](../img/02-default-text-english-annotated.png)

Default Text tab, shown in English — the app's default state.

## 3. Switch the app's language to Japanese

![Switch the app's language to Japanese](../img/03-dashboard-language-english-annotated.png)

The Dashboard has a "Language" dropdown (bottom right) that sets the app's own display language, currently English.

## 4. Default text is prefilled in Japanese

![Default text is prefilled in Japanese](../img/04-default-text-japanese-prefill-annotated.png)

Default Text fields are now prefilled with Japanese copy after switching the app language to Japanese.

## 5. Translate into other store languages

![Translate into other store languages](../img/05-translation-french-annotated.png)

Translation tab: left column is the English default (read-only), right column is the editable translation for the selected language (French shown).
