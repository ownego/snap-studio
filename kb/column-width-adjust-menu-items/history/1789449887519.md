# Column Width — Adjust the Width of Menu Items

## What it does
Column Width lets you set how much space a header item takes up in its menu row, instead of letting every item in that row share the space evenly. Use it to make one column of a mega menu wider or narrower than the others.

## 1. Open a header item's toolbar

![Open a header item's toolbar](../img/01-hover-edit-icon-annotated.png)

Open the menu editor and pick the mega menu you want to edit from the tabs above the preview (here, **Simple Mega**); Column Width applies to menus that use multiple header/submenu columns like this one.

Hover over a header item in the preview and a small toolbar appears above it: a drag handle, then three icons — **Column width**, **Edit** (pencil), and **Delete**. These icons are hidden until you hover over the item, so don't worry if you don't see them right away. Click the pencil icon to open that item's settings.

## 2. Find Column width in the item editor

![Find Column width in the item editor](../img/02-item-editor-column-width-annotated.png)

Clicking the pencil icon replaces the **Step 1 / Step 2** tabs on the left with that item's own settings — you'll see its title at the top with a back arrow to return to the item list. Scroll down to the **Column width** field, shown here set to its default, **Automatic**.

Each submenu row is divided into 12 columns, and Column width sets how many of those 12 columns this item takes up — the item's width becomes exactly that fraction of the row, no more and no less. A couple of rules for how the 12 columns get shared out:

- **All items left on Automatic** — the row splits its 12 columns evenly between them. For example, 3 items in a row would each get 4/12.
- **One item set to a fixed width, the rest Automatic** — the fixed item keeps exactly the width you set, and the Automatic items share whatever columns are left over. For example, with 2 items where the first is set to 8/12, the second automatically becomes 4/12.

## 3. Set a fixed column width

![Set a fixed column width](../img/03-fixed-column-width-preview-annotated.png)

Change **Column width** from Automatic to a fixed value — here, **6/12** (highlighted, bottom left). The preview updates right away (highlighted, top): the item's column becomes exactly half the menu's width, while the other items — still set to Automatic — automatically share whatever width is left between them.

> **Note:** If the column widths in a row add up to more than 12, the item that overflows moves down and starts a new row.

> **Important:** Column width has no effect if the Masonry layout feature is turned on for this menu. For an item using the Image layout, its Image width also can't be set wider than the item's own column width.

## 4. Or use the shortcut icon on the item

![Or use the shortcut icon on the item](../img/04-hover-column-width-icon-annotated.png)

There's a faster way to reach the same setting, still from the **Step 1: Create Menu** tab. Go back to the item list (back arrow), hover the item in the preview to bring its toolbar back, then click the **leftmost** icon — its tooltip reads **Column width** (highlighted). This opens a small picker right on the item, without opening the full item editor from the previous two steps.

## 5. Pick a column number

![Pick a column number](../img/05-column-width-popup-annotated.png)

The picker lists **Auto**, then the numbers **1** through **12**. Click a number to set the item to that many of the row's 12 columns — the same result as typing it into the Column width field. Click **Auto** to go back to sharing space evenly with the other items.
